## Что лежит здесь

Каждый репозиторий оформлен по одному стандарту: бизнес-контекст, схема работы, честная граница «что моё, что AI», роль в проекте.

- **[ai-vacancy-analyzer](https://github.com/Kris-Tsilik/ai-vacancy-analyzer)** — AI-оркестратор на n8n и YandexGPT API: парсинг, структурирование данных и запись результатов в Google Sheets.
  - Контекст: личная инициатива, прикладное применение LLM для задач сбора и структурирования данных.
  - Моё: требования, структура промпта, валидация и тестирование. Код написан AI-ассистентом по моей спецификации.
  - Статус: рабочий, схема воркфлоу в README.

- **[yandex-routes-excel-merger](https://github.com/Kris-Tsilik/yandex-routes-excel-merger)** — настольный инструмент сотрудника Яндекс Маршрутизации: склейка результатов расчёта маршрутов для анализа.
  - Контекст: один из элементов автоматизации проекта Route Planning (трудозатраты с 6 сотрудников до 1, срок подготовки с 2 недель до 2 дней).
  - Моё: бизнес-правила, включая взаимоисключающую склейку и правило dropped locations, тест-сценарии, внедрение. Код написан AI-ассистентом по моей спецификации.
  - Статус: используется сотрудниками в процессе, Mermaid-схема в README.

- **[performance-tracking-excel-refresh](https://github.com/Kris-Tsilik/performance-tracking-excel-refresh)** — автоматизация обновления Excel-файлов отчётности Performance Tracking (Jupyter Notebook).
  - Контекст: регулярная отчётность, которая раньше обновлялась вручную.
  - Моё: правила обхода папок и фильтра, обработка ошибок и таймаутов, тестирование на реальных файлах. Код написан AI-ассистентом по моей спецификации.
  - Статус: используется в процессе, схема работы в README.
